Delegated authorization and runtime policy enforcement for multi-agent AI systems. A sub-agent can never act beyond the authority the human originally granted, even when a document prompt-injects it. Every decision is made by deterministic backend code, not by the LLM.

How a tool call is decided

  1. Capability check: Ed25519 signature, issuer, audience, expiry, known & unrevoked, task open, whole agent chain active, presented by its own subject.
  2. Scope check: the action must be granted, and the resource must be inside a granted pattern (no ../ tricks).
  3. Policy rules (policies/default.json): deny rules, then approval rules, which can only restrict and never grant.
  4. Human approval: bound to a SHA-256 of the exact action and parameters, expires in 10 minutes, usable once.
  5. Record, then execute: every decision and event is written before the mock tool runs.
